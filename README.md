# The Discharge Project

A static personal research website.

## Structure
- `index.html` — home
- `essays.html` — long-form essays
- `research.html` — papers and preprints
- `framework.html` — the evolving conceptual framework
- `notebook.html` — raw notes and fragments
- `about.html` — researcher/project page
- `assets/style.css` — visual design
- `assets/main.js` — mobile navigation

## Publish for free
1. Create a GitHub account.
2. Create a repository named `yourusername.github.io`.
3. Upload all files and folders from this project.
4. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
5. Your site will be available at `https://yourusername.github.io/`.

## Before publishing
- Replace `hello@example.com`.
- Replace placeholder GitHub/Google Scholar links.
- Add your real name and short biography.
- Replace placeholder essays/papers with your actual texts.
- Buy a domain later if desired.
